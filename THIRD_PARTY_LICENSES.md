# Third-party software

Long After Dark ships three programs: `LongAfterDark.scr` (the screen
saver), `adhostwin.exe` (the emulation host) and `adimport.exe` (the
importer). They build in some code this project did not write. This file
says what it is, under what licence it is redistributed, and where to get
its source.

Nothing here is an original After Dark file: the copyrighted After Dark
modules are never shipped. The user imports them with `adimport.exe` from
their own disc, image or folder, or from the Internet Archive.

All three programs are linked statically, so they carry the code below
inside them and need no DLLs of their own. `tools/bootstrap.sh` fetches the
libraries at the revisions pinned in `tools/versions` into `third_party/win/`
(gitignored) and builds them.

## Vendored in the repository: the x86 emulator (`adhostwin.exe`)

| Project | Licence | Source |
|---|---|---|
| [resource_dasm](https://github.com/swannman/resource_dasm) branch `afterdark-perf`, commit `02d8ea9a58eaf559a9194601b33d98723c9d4f60` (a fork of [fuzziqersoftware/resource_dasm](https://github.com/fuzziqersoftware/resource_dasm)): its x86 emulator, `EmulatorBase`, `MemoryContext`, `InterruptManager` and `Expression`, vendored and modified (namespace `adw::cpu`, 16-bit protected-mode segmentation, x87, file-mapping-backed memory) | MIT, © Martin Michelsen | `host/cpu/src/` (licence text: `host/cpu/LICENSE.resource_dasm`) |

Each vendored file says in its header that it is derived and modified.
`X86Exec.cc` is the execution half of upstream's `X86Emulator.cc`, largely
rewritten; `X87.cc` is this project's own. Nothing else in the repository is
third-party code. One file is generated from third-party data:
`host/win16/signatures16.cc` lists the Win16 system DLLs' entry points
(ordinal, name, argument size), generated by a research script from
[Wine](https://www.winehq.org/)'s `.spec` files (Wine is LGPL-2.1-or-later).
It holds those interface facts only, no Wine code.

| Project | Built into | Licence | Source |

| [zlib](https://zlib.net/), commit `767c4c947852e143f582c85f14cf573411df1b35` | `adimport.exe` (raw inflate for the After Dark 3.x installers' PKZIP archives) | zlib, © Jean-loup Gailly and Mark Adler | `third_party/win/zlib` (licence text: `LICENSE`) |

phosg is built against zlib too, but none of zlib's code ends up in the
programs that link phosg: only `adimport.exe` contains it.

The PKZIP decryption in `adimport.exe` ("ZipCrypto", from PKWARE's published
APPNOTE) and its ISO-9660, FAT and ZIP readers are this project's own code.
No external extraction tools are used.

## Toolchain runtime (all three programs)

The programs are built with [llvm-mingw](https://github.com/mstorsjo/llvm-mingw)
`20260922` (UCRT, x86_64) and linked with `-static`, so each one contains the
parts of these runtimes it uses:

| Project | Licence | Source |
|---|---|---|
| LLVM `libc++`, `libc++abi`, `libunwind`, `compiler-rt` (builtins) | Apache-2.0 WITH LLVM-exception (the exception lifts the notice requirements for runtime code embedded in a compiled program like this) | [llvm-project](https://github.com/llvm/llvm-project); the toolchain's `LICENSE.TXT` |
| mingw-w64 runtime (C runtime start-up code, its helper library and import libraries) | the mingw-w64 runtime licence: BSD-style, with the notices of the parts it includes (gdtoa, parts of the math library and others) | [mingw-w64](https://www.mingw-w64.org/), as built by llvm-mingw; the toolchain's `x86_64-w64-mingw32/share/mingw32/COPYING.MinGW-w64-runtime.txt` |

The toolchain's winpthreads library is not linked into any of them.

## Windows itself

Everything else comes with Windows and is used as installed: the Universal C
Runtime, GDI, GDI+, Direct2D, WIC, DWM, the common controls, COM, WinHTTP
(the Internet Archive downloads), CNG (MD5), Core Audio (WASAPI, the modules'
sound) and WinMM (the `waveOut` fallback, and MIDI through the Windows MIDI
mapper, normally the Microsoft GS Wavetable Synth). The sound decoders (IMA
and Microsoft ADPCM) and the MIDI file player are this project's own code.

## Build and test only (never shipped)

* The llvm-mingw toolchain and ninja, downloaded into `third_party/toolchains/`
  by `tools/bootstrap.sh` and checked against the sha256 pinned in
  `tools/versions`. CMake and Git for Windows' bash are used as installed.
* phosg is also linked into the importer's tests, which use it to read the
  importer's JSON independently of the code that writes it.
* An unmodified resource_dasm clone at `third_party/win/resource_dasm`, when
  present, is compiled into the CPU benchmark (`cpu_perf`) to compare
  against upstream.
